# 0.1.1：Blazor 手寫練習

版本由 0.1.0 增加為 0.1.1。

## 變更

- 原樣複製 AGENTS.md、CLAUDE.md，SHA-256 與 Downloads 來源一致。
- 新增 .NET 10 ASP.NET Core 主機、Blazor WebAssembly PWA 與 C# 逐筆判定。
- 提供 99 個符號、174 筆軌跡、注音真人讀音及預製合成語音。
- 新增逐筆示範與描寫、重試、完成紀錄、離線快取及響應式畫面。
- 建立文件、教材、離線與核心驗證，更新兩處文件索引。

## 限制與驗收

17 個核心測試、7 個 JavaScript 測試與 Release 發布通過。瀏覽器描寫、離線音訊與下載中斷重試結果見 [交付驗證紀錄](../verification.md)。實體 Android 觸控與全部讀音人工聽辨待驗收；沒有對外部署，沒有自動 commit。判定為固定教材軌跡比對，不是任意自由手寫辨識。

建議 commit message：`feat: 新增 Blazor 兒童手寫練習與離線教材，版本 0.1.0 → 0.1.1`
