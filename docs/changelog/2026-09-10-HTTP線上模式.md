# 0.1.3 HTTP 線上模式

## 問題

一般 HTTP 網址不屬於安全來源，瀏覽器不提供 Web Locks。0.1.2 因此把第一個分頁也判定為無法取得寫入權，使用者只能看到「先讓另一個小手完成練習」。

## 變更

- 保留 HTTPS／localhost 的 Web Locks 寫入鎖。
- Web Locks 不可用時，改以 localStorage token 建立單一分頁租約；每 2 秒續租，6 秒後失效，保存前再次確認所有權。
- HTTP 頁面可在線建立孩子、自由練習、闖關、取得徽章及保存進度。
- 頁首明示「HTTP 線上模式 · 離線功能需 HTTPS 或 localhost」，並區分另一分頁占用與本機儲存遭封鎖。
- 版本由 0.1.2 更新為 0.1.3。

## 限制

瀏覽器只允許 HTTPS 或 localhost 使用 Service Worker，因此一般 HTTP 必須保持連線，無法安裝或驗收 PWA 離線功能。分頁異常關閉時，本機租約最久約 6 秒後才能由另一頁取得。

## 驗證

- `dotnet test Handwriting.slnx --no-restore`：26 項通過。
- 全部 Node 測試：HTTP 租約取得、第二分頁隔離、釋放後接手、token 被取代時停止保存、Web Locks 失敗後降級，以及 HTTP 狀態文字均通過。
- 教材檢查通過 99 個符號與 174 筆；18 個文件通過 UTF-8 BOM、CRLF 編碼檢查。
- Release 發布至 `artifacts/publish-0.1.3-http` 成功。
- Chromium 以 `http://10.1.1.70:5095` 非安全來源驗證正式發布產物：頁首顯示 HTTP 線上模式，第一分頁可保存、第二分頁被阻擋，關閉第一頁後可接手既有成果。

實際公開 IP 與 Android Chrome 仍需在部署環境人工驗收。
