# 維護規範

## 1. 開發與驗證

使用 .NET 10 SDK，先執行核心測試，再正式發布。涉及逐筆判定要加入真實教材與負面軌跡回歸；離線行為以正式發布版本驗證。Node.js 內建測試執行器與 Python 用於輔助檢查，不是網站執行依賴。

所有指定文件使用 UTF-8 BOM、CRLF；手動執行 `pwsh -File scripts/Test-DocsEncoding.ps1`。腳本驗證編碼、替代字元及換行；中文語意與誤植仍需人工閱讀。根目錄兩份外來規範保持原樣。

## 2. 版本與紀錄

版本來源為 `src/Handwriting.Server/appsettings.json` 的 Version。初始基準 0.1.0，本次正式交付為 0.1.1。每次新交付建置內容只增加 Patch 1；同一內容重跑測試不再增加。畫面版本要同步。

每次版本異動必須完成三件事：在 docs/changelog 新增日期與主題檔案、更新 docs/changelog/README.md、更新 docs/README.md。紀錄列出變更、驗證結果及未驗收限制。不得自動 commit；提供含新舊版本的建議訊息，由使用者決定。

## 3. 發布與離線

部署 artifacts/publish 內容至支援 ASP.NET Core 的 HTTPS 主機；目前未對外部署。反向代理須正確提供 HTTPS 與靜態資源 MIME 類型，不將 service-worker.js 或 index.html 設為長效快取。預設網站部署在根路徑，若改子路徑須同步 base、manifest 與靜態主機設定。

Android 平板連區網 HTTP 無法啟用 PWA，實機須使用受信任 HTTPS。localhost 僅供電腦本機測試。只在所有必要資源成功下載後顯示可離線；新版本等待所有舊分頁關閉再啟用。瀏覽器清除／回收網站儲存後需重新下載。
