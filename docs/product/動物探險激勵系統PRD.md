# 動物探險激勵系統 PRD

版本：0.1.2。對象：4–6 歲孩子與陪伴家長。

## 目標與範圍

以動物探險的收集成就鼓勵開始、完成與反覆練習。不設排名、扣分、帳號、同步、刪除個人資料或關卡鎖定。成果只保存在本機瀏覽器。

## 需求與驗收標準

| 編號 | 需求 | 驗收標準 |
|---|---|---|
| PRD-01 | 多孩子暱稱與頭像 | 可建立、切換、編輯；成果獨立，舊資料只移入首位孩子 |
| PRD-02 | 三個入口 | 自由練習、探險闖關、我的徽章均可直接使用 |
| PRD-03 | 88 枚徽章 | 開始 4、收集 12、練習 12、闖關 60；達標只發一次 |
| PRD-04 | 徽章牆 | 分類與題型篩選，灰色／彩色與文字狀態、進度、條件語音 |
| PRD-05 | 抽題 | 5／10／20 題，全部教材、單科或混合，同輪不重複且混合涵蓋所選科目 |
| PRD-06 | 判定與通關 | 保留描線與示範；逐筆通過、不跳題；全部完成才通關 |
| PRD-07 | 計時 | 每題 15 秒加每筆 15 秒；必要播放與換題不計時，主動重播計時 |
| PRD-08 | 暫停與中止 | 暫停遮題，背景自動暫停；重整／離開中止，保留已完成符號 |
| PRD-09 | 次數與里程碑 | 依單科／綜合與兩模式分開，每場算一次；10／20 題另發首次徽章 |
| PRD-10 | 本機保存 | 舊資料備份、不推測歷史闖關；單頁寫入，失敗明確提示 |
| PRD-11 | 音訊與離線 | 預製繁中語音、遵守靜音、素材可離線，慶祝合併與減少動態 |

## 使用流程

建立孩子 → 選擇自由練習／闖關 → 實際落筆 → 完成符號並保存 → 達標合併展示徽章 → 徽章牆查看下一個目標。闖關先選題型、題數、模式與判定範圍，再開始作答；結果頁提供再次挑戰。

## 徽章規則

一般練習與闖關都累積完整符號次數。不同符號收集不因重寫增加。勇敢開始以實際落筆計算。

四種教材各設開始 1 枚、完成不同符號 3／5／全部共 3 枚、完整書寫 10／30／100 次共 3 枚。五類闖關（含綜合）乘兩模式，各設通關 1／5／10／25 次及首次完成 10／20 題共 6 枚。

完整 88 枚的固定識別碼、名稱、條件與門檻列於文末，由核心規則匯出。

## 例外與預設

寬鬆與一般判定均給獎，開始前鎖定。重複完成回呼不重複結算。超時當下的提交不算完成。混合題只累積綜合闖關，符號學習仍回到原題型。重整不恢復場次。不以倒數施加扣分，未通過仍顯示努力成果。

計時常數為初始值，交付時列明平板試玩與語音人工聽辨狀態；首版不蒐集雲端分析資料。

獲獎判定與保存於達標時進行；慶祝通知在自由練習整字完成或闖關結果頁合併呈現，落筆途中不插入會推移畫布的內容。
