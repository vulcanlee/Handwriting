# 動物探險激勵系統技術設計

## 架構與實作順序

1. 核心模型與測試：AdventureState／ChildProfile、BadgeCatalog、ChallengeRun；沿用 StrokeEvaluator。
2. 瀏覽器保存：版本二狀態、舊資料備份與移轉、安全來源 Web Locks 與 HTTP 本機租約鎖。
3. 共用 PracticeBoard：逐筆描線與音訊；Home 管理孩子、頁面、徽章與場次。
4. 原創徽章與預製語音、離線資源；瀏覽器驗收與文件收斂。

## 資料與結算

每位孩子保存 Progress、StartedCategories、Challenges、Awards。徽章定義為固定 ID、分類、題型、模式、條件與門檻。Award 保存取得時間與是否由舊資料補發；補發時間留空，不假造歷史時間。

PracticeBoard 使用獨立 PracticeSession；只有有效完成回呼才由父層累積孩子進度。場次用索引阻止重複題目結算，結束後不可再次發獎。切換孩子取消互動並移除舊回呼作用。

## 計時狀態

ChallengeRun 接收單調時間，區分作答、系統提示、暫停、通過、超時、中止。畫面週期刷新倒數；提交前重新檢查截止時間，不能靠背景節流延長作答。必要示範及音訊完成後才開始計時。暫停遮題，背景返回須手動繼續。

## 保存與相容性

little-hands-state-v2 保存多孩子。保留 v1 原始資料作備份，首次建立孩子時移入，只有可證明的開始與練習成果補發徽章。不新增 API。HTTPS／localhost 優先用 Web Locks 取得單一寫入權；一般 HTTP 沒有 Web Locks 時，以 localStorage 保存隨機 token 與到期時間，2 秒續租、6 秒失效，寫入前再次核對所有權。保存失敗仍保留當次記憶體成果。

## 音訊與離線

徽章條件與鼓勵語預製為 MP3。所有原創 SVG／音檔隨既有 PWA manifest 快取，孩子操作時不呼叫語音雲端。靜音及取消播放不得造成計時掛起。一般 HTTP 可在線載入所有功能，但 Service Worker 受瀏覽器安全規則限制，不註冊也不提供離線快取。

## 驗證

核心測試涵蓋所有門檻、抽題與時間邊界；Node 測試保存及鎖定；正式發布網站驗證操作、隔離、重載及離線。實際命令與結果記於驗證文件。

獲獎判定與保存於達標時進行；慶祝通知在自由練習整字完成或闖關結果頁合併呈現，落筆途中不插入會推移畫布的內容。

## 儲存格式與介面

`AdventureState` 序列化使用 camelCase，版本二以單次 localStorage.setItem 寫入完整狀態。未完成場次不持久化。

```json
{
  "version": 2,
  "activeChildId": "child-id",
  "muted": false,
  "relaxed": true,
  "legacyProgress": null,
  "children": [{
    "id": "child-id",
    "name": "小兔",
    "avatar": "numbers",
    "progress": {},
    "startedCategories": [],
    "challenges": {},
    "awards": {}
  }]
}
```

- `progress`：符號 ID 對應原有 PracticeProgress（completed、successfulAttempts、lastPracticed）。
- `startedCategories`：已實際落筆的題型集合。
- `challenges`：例如 `numbers-timed`／`mixed-adventure`，值含 wins 與 completedLengths（5、10、20 的集合）。
- `awards`：固定徽章 ID 對應 earnedAt 與 imported；舊紀錄補發的 earnedAt 為 null。
- `BadgeCatalog.Create` 匯出完整定義；`Award` 比對數值且只新增尚未取得的徽章。
- `ChallengeRun.Draw` 產生題目；`CompleteQuestion(index, now)` 要求索引等於目前進度，`Settle(child)` 僅在通過後成功一次。
- 狀態值為 playing／passed／timeout／aborted，另以 Paused 區分休息、作答起始時間區分提示與作答。
- `PracticeBoard` 接收符號、RunKey、判定與靜音，發出開始／完成／提示忙碌事件；RunKey 隨孩子或題目改變，必須使用 Razor 動態值傳遞。

## 驗證與復原邊界

保存前後均驗證基本結構，日期使用實際曆法檢查，C# 載入另捕捉 JSON／JS 例外。異常資料保留原文並禁止覆寫。儲存拒絕時可保留當次記憶體成果，但不承諾關閉後恢復。

另一頁持鎖時顯示說明；關閉原頁後重載才取得鎖。HTTP 分頁未正常釋放時，租約最久約 6 秒後可重新取得；租約遭取代後原頁停止保存。瀏覽器封鎖 localStorage 時顯示儲存權限訊息並禁止練習。第一位孩子的舊資料補發不播放歷史慶祝。不支援帳號、雲端同步、恢復未完成闖關或跨裝置移轉。
