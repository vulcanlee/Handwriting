# 小朋友手寫練習網頁設計

## 對象與範圍

供 4–6 歲初學者，以 Android 平板 Chrome 手指練習為主，另支援滑鼠與觸控筆。數字 0–9、英文大寫 A–Z、小寫 a–z、37 注音，共 99 符號。無聲調、單字、帳號與雲端同步。

## 練習流程

四分類自由選字、不鎖關。先看筆順編號、起點、方向箭頭與逐筆動畫，可重播或聽讀音。開始後在淡色線條上描寫，突出目前筆畫；放手後檢查。失敗保留前面成功筆畫，文字與語音引導重畫當筆。全字完成才增加一次成功練習紀錄，提供重練與下一個；分類末尾返回選字。

## 判定

圖例與判定共用逐筆資料，座標正規化至 0–100。記錄時間排序的軌跡，重採樣後比較長度、完整度、方向與路徑距離。封閉筆畫額外比較旋向。拒絕點擊、缺段、反向、錯筆、越界與塗鴉；短點筆畫仍需遵守方向與完整度。提供一般／寬鬆容錯，預設寬鬆。門檻需在真實平板持續校準，不宣稱能辨識所有自由書寫變體。

## 架構與狀態

.NET 10 ASP.NET Core 主機搭配獨立 Blazor WebAssembly PWA；C# 核心執行判定。SVG 呈現圖例，Canvas 呈現即時筆跡，Pointer Events 擷取單一指標。取消、切題、視窗變化需清理未完成筆畫；不讓舊事件污染新題。

SymbolDefinition 含分類、排序、字形、逐筆定義與語音；StrokeDefinition 含路徑、座標、指令、語音；StrokeAttempt 與 StrokeEvaluation 表達輸入與判定；PracticeSession 管理目前筆畫與完成；PracticeProgress 保存完成標記、成功整字次數與最後練習時間。

進度與設定保存在 localStorage，無法儲存仍可練習。音訊使用預製檔案，切題、靜音、重播會停止舊音訊。完整發布資源與音檔透過 service worker 快取；全部成功才標記可離線。新舊版本不混用，更新不強制中斷練習。

## 教材與視覺

教育部開放部件提供 37 注音的筆順軌跡與真人錄音。英文與數字為原創固定教學寫法，小寫 a、g 採單層。英文數字目前採合成音檔，待人工聽辨。暖白、綠色及暖橘搭配大按鈕；橫向並排兩區，直向上下排列。參考教材的大格子、描線概念，不搬用部落格圖片。

## 0.1.2 動物探險擴充

現行首頁提供自由練習、探險闖關與我的徽章。每位孩子有獨立本機紀錄，原練習畫面已整理為共用 PracticeBoard，核心筆畫判定維持原規則。新增需求以 [動物探險 PRD](product/動物探險激勵系統PRD.md) 為準；多孩子資料、徽章與計時狀態詳見 [技術設計](architecture/動物探險激勵系統技術設計.md)。
